Multi-LLM × Service Bus

從 Azure Service Bus 接收 Agent 任務，下載 Blob 設定與資料， 呼叫 LLM 產生「對話樹（ConversationTree）」並寫回 Blob 與輸出佇列。 多 LLM 動態切換（Azure OpenAI / vLLM 自架端點 / Anthropic Claude）， Claude 端把 Structured Output 自動轉成 Tool Use 格式； 5 次重試 + 模型降級 + 指數退避， json_schema 不支援時自動退回 json_object； TreeBuilder 以 memoization 避免重複 LLM 呼叫。 完整工程化：xUnit、BenchmarkDotNet、Dockerfile、ACR Pipeline、App Insights / OpenTelemetry。

Feature · Data Pipeline

資料過濾管線
Rule Engine × Idempotent Blob

訊息佇列之間的資料過濾中介，合併多個 Blob 設定與資料後依規則過濾並寫回輸出佇列。 30+ 種 FilterType（時間相對範圍、班別區間、字串包含、數值比較…）， 規則以 blockSerial 分組，組內 OR、組間 AND； 自訂 helper 支援 Items.[*].Timestamp 萬用字元路徑攤平比對； 內容定址 輸出 Blob 以 SHA256 命名（{hash}.json），重送天然冪等； traceId 由 messageId + 業務識別碼 + 時間戳組成，整條管線 log 可串聯。

Cover Feature · Spec-Driven Dev · 2026

規格驅動微服務 —
Spec Kit × Spring Boot 4

以 GitHub Spec Kit（specify → plan → tasks → implement） 規格驅動工作流，把一支既有的 FastAPI 路由重寫為 Spring Boot 4 / Java 17 可獨立部署、可獨立測試的微服務。 .specify/memory/constitution.md 為 ratified 專案憲章 v1.0.0， 內含 5 條 principles；每個 plan 階段都必須通過 constitution check 才能進入下一階段。 before_* / after_* hook 在每階段自動 commit 到 feature branch， spec → plan → tasks → code 完整可追溯。

無 ORM SP 呼叫：SimpleJdbcCall 顯式宣告所有參數、停用 column metadata，避開 hardened DB account 沒有 metadata 讀取權限的雷區（這是 plan 階段就被 constitution 攔下的決策）。

凍結錯誤封套：@RestControllerAdvice 統一回傳同一份中文錯誤 envelope；SQLState / 根因 SQLException 只進 log、不洩漏到回應 — 是和前端的合約，spec 中明確 lock 住。

MDC 結構化日誌：請求識別碼推入 MDC，finally 才移除，例外情況下後續 log 都帶得到追蹤 ID；長欄位 log 時截斷至 200 字元防灌爆。

分層測試（CI 友善）：MockMvc Slice + Logging Test（把日誌格式當契約 lock 住）+ Repository H2 + Testcontainers mssqlserver 整合；CI 預設只跑單元，整合測試以 -Pintegration 顯式觸發。
